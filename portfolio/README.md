# Charan — AI Native Portfolio

A hyper-modern, AI-inspired personal portfolio for Dasari Narada Rama Krishna Charan. Built with React, TypeScript, Tailwind CSS, and Framer Motion for cinematic interactions.

## ✨ Highlights
- Neural-network inspired hero with floating analytics badges.
- Animated sections for experience, projects, skills, education, certifications, and achievements.
- AI Copilot chatbot answering common queries about Charan.
- Dynamic resume JSON exporter for AI agents or custom automations.
- Auto day/night theming and floating navigation optimized for mobile and desktop.

## 🚀 Getting Started
```bash
npm install
npm run dev
```

> Replace `public/assets/charan-resume.pdf` with the latest resume before deployment.

## 📦 Deployment
The project is ready for Cloudflare Pages or Netlify. Build using `npm run build` and deploy the generated `dist/` folder.
